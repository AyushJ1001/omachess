# Engine Profile artwork

These profile marks are packaged so Engine Profiles remain identifiable
offline. Each SVG is a lossless wrapper around the official project's source
asset:

- **Stockfish** — official project favicon at
  <https://github.com/official-stockfish/official-stockfish.github.io/blob/main/favicon.png>;
  Stockfish is GPL-3.0.
- **Leela Chess Zero** — official site logo at
  <https://github.com/LeelaChessZero/lczero.org/blob/master/static/images/logo.svg>;
  Lc0 is GPL-3.0-or-later.
- **Reckless** — official project image at
  <https://github.com/codedeliveryservice/Reckless#readme>;
  Reckless is AGPL-3.0.
The names and marks identify their respective projects and do not imply
endorsement. This provenance is also exposed as accessible text in the Engine
Profile UI.

Komodo remains a detect-only Engine Profile, but Omachess does not distribute
its artwork because no redistribution grant for that mark is documented.
